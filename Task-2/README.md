# Task 2: Exploratory Data Analysis and Sales Performance Analysis

This project includes Exploratory Data Analysis (EDA) and a Linear Regression model using Python on a sales dataset.

## Files
- `sales_sample.csv`: Dataset file with sales data.
- `Task-2.ipynb`: Jupyter Notebook containing code, visualizations, and analysis.

## How to run
1. Clone the repository.
2. Make sure both the CSV file and notebook are in the same folder.
3. Install required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn statsmodels
